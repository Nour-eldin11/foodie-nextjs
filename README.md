# Foodie

A responsive food ordering demo built with Next.js 16 (App Router), React, TypeScript, CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production export

```bash
npm run build
```

The static website is exported to `out/`.

Features: restaurant menus, search, category filters, sorting, free delivery filters, saved favorites, persistent shopping bag, quantity controls, first-order pizza discount, address editing, validated demo checkout, and latest-order confirmation. State persists in localStorage on the current browser. Demo data and prices use USD. No payments are collected and no actual orders are transmitted. Photos from Unsplash; fonts from Google Fonts.
